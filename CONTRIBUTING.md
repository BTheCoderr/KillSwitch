# Contributing to Killswitch

Killswitch is a livestream-first competitive coding show platform built with Next.js, React, TypeScript, and Supabase Realtime.

Before a pull request, run the repository's existing validation and dependency-audit workflows and check arena, producer, audience, and OBS-facing surfaces when relevant.

Prefer changes that improve broadcast reliability, producer control, accessibility, synchronization, or audience clarity without turning the project into a hosted code-execution service.

A merged commit is not automatic approval for a production deployment.
