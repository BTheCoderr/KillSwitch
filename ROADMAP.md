# Killswitch Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- four-person competitive coding battle format
- OBS-ready arena and transparent overlay
- audience voting and chaos modifiers
- protected producer controls
- Supabase-backed match state and Realtime updates
- server-anchored countdown support
- validated competitor application flow

## Improving

- show-day failure recovery
- producer readiness and rehearsal tooling
- mobile and broadcast responsiveness
- synchronization and observability

## Exploring

- optional LLM commentary without runtime dependency
- expanded show formats
- additional contestant integrations
- richer post-match recaps

## Product boundary

The broadcast experience is the product. Avoid adding infrastructure that does not directly improve the live show or production workflow.
