# Security Policy

Security fixes target the current default branch.

Report vulnerabilities privately through GitHub when they could expose producer/admin controls, contestant embeds, Supabase data, audience actions, or privileged server mutations.

Extra review is expected for producer authentication, server-only mutations, embed allowlists, Realtime policies, voting/modifier integrity, and server-anchored timing.

Never commit production secrets, privileged Supabase credentials, or private contestant data.
